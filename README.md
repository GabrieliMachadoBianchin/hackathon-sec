# Sobre

Olá! Neste repositório tem-se os códigos desenvolvidos e apresentados na II edição do Hackathon de dispositivos IoT. 


# Cyber Solutions

O tema proposto foi: "Criar soluções para melhorar a qualidade de vida dos profissionais do setor hoteleiro".

A equipe se propôs à otimizar as rotas das camareiras, ao solicitar limpeza nos quartos com cartões RFID, e adicionalmente criou um sistema para controle do peso dos carrinhos utilizados pelas mesmas. Para mais informações, leia o pdf.
